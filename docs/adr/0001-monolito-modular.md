# ADR-0001 — Monólito modular

- Status: aceito
- Data: 18/07/2026
- Fontes: GSIPRO-TEC-201 REV00; GSIPRO-EXE-301 REV00

O G-SIPRO inicia como uma única unidade implantável, com módulos de domínio explícitos e dependências controladas. Microserviços somente serão considerados diante de evidência de escala, criticidade ou autonomia operacional.
