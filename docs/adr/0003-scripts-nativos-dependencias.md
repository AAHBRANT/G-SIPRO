# ADR-0003 — Scripts nativos de dependências

- Status: aceito
- Data: 18/07/2026
- Fonte: GSIPRO-TEC-204 REV00

O pnpm permite scripts de instalação somente para `@prisma/engines`, `prisma`, `esbuild`, `sharp` e `unrs-resolver`. Qualquer inclusão exige revisão explícita do arquivo `pnpm-workspace.yaml`.
